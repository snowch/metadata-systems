## labNote

The Metadata Lab is a small data platform. It comes with the page as code and runs in your browser: nothing to install, open or sign in to. You use it through the figures. A figure that shows storage reads what the lab records, a query you build the lab runs, or you change the shop and the lab runs the week again.

It holds files, tables and a dashboard with real rows, and programs that run each night and write them. The lab reads and runs that code itself, with a query engine of its own, and runs the queries you build the same way. Nothing about the shop is stored. Each time the page loads, the lab builds the data and runs the whole week in memory, so the rows and times are the same for every reader. The week is Monday 7 to Sunday 13 September 2026, invented for this course. Every date and time comes from that week, whose last night ends early Monday 14 September, never from today or your clock. Your browser keeps your predictions, choices and answers. Nothing leaves it.
