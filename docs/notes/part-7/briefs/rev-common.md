# What every revision brief for Chapters 29 to 32 shares

Each chapter was drafted once (`docs/notes/part-7/drafts/P<n>.md`), reviewed, and the review's
upheld findings turned into the facts below. You redraft only the slots a revision brief names.

Read first, in this order: `docs/style.md`; `docs/notes/part-7/briefs/common.md` (every rule there
still holds); the chapter's first draft, `docs/notes/part-7/drafts/P<n>.md`, to see the text
around each slot you redraft. The first draft is context: do not copy a sentence of it that the
brief's facts change, and do not add anything the brief's facts do not give.

For each slot, the brief lists the facts the slot must carry, in order. Write each fact as a plain
sentence or two. Where the brief quotes a sentence in double quotes and says "keep", keep it word
for word: a test reads it. Where the brief says a slot is a list, write a Markdown list. A heading
the brief gives (`### ...`) goes in the slot where the brief puts it. A slot that is the text of a
cell the reader writes in is exactly two lines: the question, then a line of eight full stops.

Write `docs/notes/part-7/drafts/P<n>-rev.md`: one `## key` heading per slot the brief names, in
the brief's order, and nothing under each heading but the slot's text. Write the file once. Use only
the Read and Write tools. Send no messages.
